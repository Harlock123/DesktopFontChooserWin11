# AGENTS.md

Notes for anyone, human or AI agent, changing this code. `README.md` says what the tool is for; this file covers
how the code works and how to change it safely.

## What this is

A small Windows Forms tool in C# on .NET 6 (`net6.0-windows`) that replaces the Windows 11 desktop font. You pick a
font, see a sample, and apply it. Applying it writes to `HKEY_LOCAL_MACHINE`, so it must run as Administrator, and
it builds and runs on Windows only.

## Commands

```bash
dotnet build DesktopFontChooserWin11.sln          # Windows only (WinForms)
dotnet run --project DesktopFontChooserWin11      # run from an elevated prompt to apply a font
```

There are no tests yet. The only package is `Microsoft.Win32.Registry`.

## Layout

- `DesktopFontChooserWin11/Program.cs`: the entry point; starts `Form1`.
- `DesktopFontChooserWin11/Form1.cs`: all the logic.
  - The constructor warns if the process is not running as Administrator (`IsAdministrator`).
  - `button1_Click` ("Select Font") opens the font dialog `FD1` and shows the choice in `txtSample`.
  - `button2_Click` ("Apply Selection") writes the registry values described below.
- `DesktopFontChooserWin11/Form1.Designer.cs` and `Form1.resx`: the designer-generated form.

## Rules that keep it working

- **What "apply" does.** Under `HKLM\SOFTWARE\Microsoft\Windows NT\CurrentVersion`:
  - In `Fonts`, it blanks the seven `Segoe UI ... (TrueType)` entries.
  - In `FontSubstitutes`, it sets `Segoe UI` to the chosen font's name.
  - `MakeSureKeysExist` creates either key if it is missing. The user must sign out and back in to see the change.
- **This changes system settings.** Test on a machine or VM you can restore. The tool has no undo; to revert, the
  `Segoe UI` font entries must be restored by hand.
- **Designer files.** Change the form in the Visual Studio designer, or edit `Form1.Designer.cs` with care; it is
  regenerated by the designer.

## Making a change

- Keep registry writes inside the existing `try`/`catch`, which tells the user they may need Administrator rights.
- Update `README.md` if the behaviour changes.
